# 🌍 Travel Companion

A cloud-based travel planning application developed using **Snowflake, Snowpark, Streamlit, and Python**.

## 📌 Project Overview

Travel Companion provides an interactive interface for collecting and managing travel plans. Users can enter traveler details, destinations, travel dates, transportation preferences, hotel information, budget, contact details, and special requests.

The collected travel information is stored in a **Snowflake database** for efficient data management.

## ✨ Features

* 🧳 Travel booking form
* 👤 Traveler information management
* 📍 Source and destination details
* 📅 Departure and return date selection
* 🚗 Flight, Train, Bus, and Car options
* 🏨 Hotel information
* 👥 Number of travelers
* 💰 Budget management
* 📞 Contact and email details
* 📝 Special requests
* ☁️ Snowflake database integration

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Snowflake**
* **Snowpark**
* **SQL**

## 🗄️ Database

Travel plans are stored in the Snowflake table:

`TRAVEL_DB.PUBLIC.TRAVEL_PLANS`
